# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer or electronic device that you can see and touch. Examples of hardware include the keyboard, mouse, monitor, motherboard, processor (CPU), RAM, hard drive, and printer. Each hardware component has a specific purpose, such as entering information, displaying images, or storing data. Hardware is essential because it provides the equipment needed for a computer to operate and perform different tasks.
## Explain Software
Write **at least 50 words** explaining what software is.
Software is a collection of programs, instructions, and data that tells a computer what to do and how to perform different tasks. Unlike hardware, software cannot be physically touched. Examples of software include operating systems such as Windows and macOS, web browsers such as Google Chrome, and applications such as Microsoft Word. Software allows users to write documents, browse the internet, play games, and edit pictures. Without software, a computer would not know how to perform useful tasks.
## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware provides the physical components, while software gives instructions that tell those components what to do. For example, when you type on a keyboard, the hardware sends your keystrokes to the computer, and software processes the input and displays the words on the monitor. The operating system helps manage communication between hardware and applications. Both hardware and software depend on each other to perform tasks efficiently and allow users to interact with computers.
